## 功能

| 功能 | 说明 |
|---|---|
| 白名单为主过滤 | 白名单 UP / 关键词 / 分区放行；未命中名单的中间地带在严格档下默认隐藏 |
| 黑名单兑底 | 黑词（匹配标题/简介/标签/**UP名称**）/ 黑 UP / 黑分区 tid（内置固定名单，无配置UI）最高优先级——白名单 UP 发违规内容同样拦截 |
| 过滤模式开关 | popup「仅过滤黑名单」开关：开启=只拦黑名单（黑词/黑UP/黑分区/直播）其余放行；关闭（默认）=严格白名单档；底层同一状态 strictMode，即时切换 |
| L0 防闪现 | `early.js` 在 document_start 抢先隐藏卡片，`content.js` 判定后精确放行 |
| L1 API 复核 | background 查视频分区/标签复核（黑分区兜底、严格档白名单放行），BV 缓存 24h、并发 ≤3、指数退避、连续失败自动降级纯关键词模式 |
| 直播全站拦截（强制，无开关） | `live.bilibili.com` 整站拦截页 + 直播 tab / 卡片 / 导航入口隐藏，仅受总开关控制 |
| 知识卡遮罩（默认生效，无开关） | 保留B站原生首页流与布局，被拦卡片不删除而是用知识卡遮罩原位覆盖（position 遮住封面/标题，布局零空白）：遮罩清淡温柔三主题按内容轮换（天蓝·英语单词带音标释义 / 蜜桃粉·成语带释义 / 薄荷绿·小知识，低饱和高明度+双色角晕），印章角标+双线内框+楷体；随机起点+递增取模防重复，矮条卡自动切横向紧凑布局；拦截卡不可点击跳转；L1 放行时自动揭遮罩，名单变化重扫时全部重置 |
| 插件全局开关 | popup 总开关一键启停全部过滤能力 |
| 播放页守卫 | 标题同步审 + API 异步审，命中即全屏拦截层 + 暂停播放器 + 返回首页 |
| UP 名称批量导入 | 粘贴文本导入（换行/逗号/顿号/分号/Tab 分隔），解析预览、冲突标记、一键导出 |
| mid 自动回填 | 浏览B站遇到名单 UP 的卡片时自动回填（无需任何操作） |
| 从我的关注同步名单 | 拉取B站关注列表：名单中同名无 mid 条目回填；名单里还没有的关注UP直接带 mid 新增入白名单（家长自己关注过的真实账号，免粉丝闸；新增前有确认弹窗） |
| 智能补全 | 配置页按名称搜索B站用户，勾选入库（防自动配错） |
| 一键关注白名单UP | 全自动：有 mid 直接关注；无 mid 自动按名称搜索，同名候选过「完全同名·粉丝最多·粉丝≥1万」三重闸后回填并关注（同名全等闸防配错，粉丝闸防假冒账号）；需登录B站，关注后原生推荐流增加白名单UP曝光 |
| UP 一键拉黑 | 卡片 hover 🚫 按钮，立即加入黑名单并全站移除 |
| 屏蔽记录 | 最近 500 条（标题/UP/命中规则/时间），popup 速览最近 20 条 |

## 使用

- **popup**：总开关 / 仅过滤黑名单开关（关=严格白名单档）/ 最近屏蔽速览（直播拦截与知识卡遮罩为强制行为，不设开关）
- **配置页**（右键插件图标 → 选项）：关键词库（增删、导入导出、恢复默认、支持 `/正则/i` 条目）、UP 名单（表格管理、批量导入导出、智能补全、一键关注白名单UP）、屏蔽记录
- 词库默认值见计划书 §8；白名单 UP 默认为空（不预置种子），由家长在配置页自行导入，mid 会在浏览/关注过程中自动回填

## 防绕过说明（家长须知）

1. **无密码保护**：孩子可直接关闭 popup 开关或移除插件。这是浏览器扩展层的能力边界，纯前端无法根治；架构已预留密码开关位，后续可补。
2. **无痕窗口不生效**：MV3 content script 默认不在无痕模式运行，请在 Chrome 设置中禁用无痕浏览（`chrome://settings` → 搜索"无痕"）。
3. **插件数据仅存本地**（`chrome.storage.local`），不外发任何数据；API 请求仅访问B站官方接口并复用浏览器登录 Cookie（大会员内容可直接观看）。
4. 建议配合系统级家长控制（如 Microsoft Family Safety / Screen Time）形成多层防护。

## 目录结构

```
bilibili-teen-up/
├── manifest.json        # MV3；host_permissions: https://*.bilibili.com/*
├── background.js        # service worker：API 查询、wbi 签名、BV 缓存、限流降级
├── early.js             # document_start：防闪现隐藏 + 直播整站拦截
├── content.js           # DOM 过滤引擎 + 播放守卫 + 知识卡遮罩注入 + 拉黑/回填
├── content.css          # 拦截层 / 横幅 / 知识卡遮罩样式
├── lib/
│   ├── defaults.js      # 默认词库、分区常量、storage schema
│   ├── judge.js         # 判定链纯函数（DOM 层与 API 层共用）
│   └── wbi.js           # wbi 签名（内置 MD5，service worker 安全）
├── popup/               # popup.html/js/css
├── options/             # options.html/js/css
├── icons/               # icon16/48/128（gen-icons.ps1 可重新生成）
└── smoke-test.js        # 判定链/MD5/解析冒烟测试：node smoke-test.js
```
